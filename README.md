# PCU Campus Connect

A frontend-only campus events website built with HTML, CSS, and vanilla JavaScript.

## Run in VS Code
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension and choose **Open with Live Server**.

## Features
- Search and category filtering
- Sort events by date, name, or available places
- Save favourite events
- Student registration form and duplicate-registration check
- My registrations section
- Download calendar (`.ics`) files after registering
- Organizer demo tools to add/remove events
- Browser localStorage persistence
- Responsive layout

## Important limitations
This is a frontend prototype. It has no server, database, authentication, or shared event data. Organizer tools are not protected; do not use this version for real student records or official registrations. Changes are stored only in the current browser. Sample events are for demonstration and are not verified official announcements.
